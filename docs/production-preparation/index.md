# Preparation for production

Prepare models in a development installation. Scientists submit the model and
its evaluation requirements. Engineers use the engineering queue to review the
handoff, prepare the artifacts, and retain validation evidence.

| Where you are | Where to go |
| --- | --- |
| A model is running on a development Triton instance | [Prepare a serving model](prepare-serving-model.md) |
| You have a model or repository stored in S3 | [Submit a scientist handoff](../scientist-handoffs.md) |
| You need to capture a development experiment | [Capture an experiment snapshot](../experiment-snapshots.md) |
| You have an assigned preparation task | [Open a task workspace](../task-workspaces.md#engineering-queue) |
| You are reviewing a release | [Review validation and security evidence](../validation-contracts.md#trusted-validation-evidence) |

Production rollout requires independent approval. For the actions available in
each installation mode, see [Installation capabilities](../installation-policy.md).
