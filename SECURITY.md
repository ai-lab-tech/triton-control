# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of Triton Control.
Users should upgrade to the most recent release before reporting a
vulnerability that may already have been fixed.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a Vulnerability

Do not report suspected security vulnerabilities in public issues, pull
requests, or discussions.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's
   [Security advisories](https://github.com/ai-lab-tech/triton-control/security/advisories)
   page.
2. Select **Report a vulnerability**.
3. Include affected versions, impact, reproduction steps, and any proposed
   mitigation.

Remove credentials, access tokens, personal data, and unrelated confidential
information from the report. If private vulnerability reporting is not
available, contact a project maintainer privately through GitHub without
disclosing vulnerability details in a public issue.

## What to Expect

Maintainers will acknowledge a report as soon as reasonably possible, assess
its impact, and coordinate remediation and disclosure with the reporter. Please
allow maintainers time to investigate and release a fix before public
disclosure.

Good-faith security research and responsible disclosure are appreciated.
